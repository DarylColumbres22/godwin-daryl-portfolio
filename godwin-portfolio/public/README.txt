Files to drop into this folder
==============================

1. Godwin_Daryl_Columbres_Resume.pdf
   The "Download resume" buttons in the site link to /Godwin_Daryl_Columbres_Resume.pdf.
   Put the PDF here with exactly that filename and the buttons will work.
   To use a different filename, edit `resumePath` in src/data/profile.js.

2. Project screenshots (optional)
   Create a folder named "projects" here and save your images, e.g.
   public/projects/telegram-receipt-automation.png
   Then set the `screenshot` field for that project in src/data/projects.js to
   "/projects/telegram-receipt-automation.png".
   Until a screenshot is set, the project modal shows a neutral placeholder.

3. og-image.png (optional)
   A 1200x630 preview image for link sharing. After adding it, update the
   og:image meta tag in index.html.
